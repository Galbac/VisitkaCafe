# Заполнение сайта через админку

Адрес: https://bezvreda05.ru/admin/. Логин `admin`. Пароль выдаётся владельцу отдельно и в Git не хранится. В правом верхнем углу доступна смена пароля.

- **Продукты → Добавить**: название, описание, технология, фотография, вес, состав (каждый ингредиент с новой строки), КБЖУ на 100 г. URL формируется автоматически; можно задать свой. Сертификат прикрепляйте только настоящий. Сохраняйте реальные значения состава и аллергенов.
- **Изображения галереи**: фотография, подпись, порядок и флажок «Активно». После сохранения активные изображения появляются на главной.
- **Сертификаты**: название, описание, изображение документа, порядок. Флажок «Активен» публикует документ. Непубличный демо-пример с логотипом не является сертификатом: замените его реальным документом до публикации.
- **Отзывы**: имя, текст/скриншот, флажок «Опубликован». Отзывы, отправленные посетителями, сначала проходят модерацию.
- **Элементы «Не содержит»**: название, иконка PNG/безопасный SVG и порядок. Заполняйте только подтверждённые свойства настоящих продуктов. Тестовые утверждения об отсутствии аллергенов не создаются.
- **Заявки на заказ**: карточка заказа и статус «Новая / В работе / Выполнена / Отменена».
- **Сообщения с сайта**: обращения и флажок «Обработано».

## Демоданные

Команда `python manage.py seed_demo` создаёт шесть товаров, два изображения галереи, три явно тестовых отзыва, два примера заказов, одно обращение и один **неопубликованный** пример карточки документа. Используются существующие иллюстрации проекта, не реальные фотографии предлагаемых блюд. Команда не создаёт пароли и не отправляет Telegram/почту. Повторный запуск не переписывает созданные записи или ваши изменения в них.

На сервере:

```sh
cd /root/dietfactory
docker compose -f docker-compose.yml exec -T web python manage.py seed_demo
```

Все тестовые записи помечены «Демо». Удалите их через админку после знакомства с интерфейсом и добавьте настоящую продукцию. Для превращения демо-карточки в настоящую нужно заменить все условные значения и фотографию, убрать «демо» из названия и изменить URL, удалив префикс `demo-seed-`.

Контакты и тексты главной сейчас заданы в шаблонах проекта и не редактируются этими разделами админки.
